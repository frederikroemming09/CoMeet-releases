# CoMeet releases

Builds of CoMeet, a private Mac app that records and transcribes meetings entirely on the Mac.
This repo only holds the signed, notarized app and the Sparkle update feed (`appcast.xml`).
The source code is private.

Install: download `CoMeet.zip` from the [latest release](https://github.com/frederikroemming09/CoMeet-releases/releases/latest),
unzip it and drag `CoMeet.app` to Applications. After that, CoMeet updates itself.
